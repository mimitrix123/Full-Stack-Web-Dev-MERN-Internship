# MERN Full-Stack Web Development Internship

Complete solutions for Weeks 1–4 based on the supplied assignment PDFs.

## Structure
- `week-1/` — HTML/CSS/JavaScript practice, portfolio, reusable React components, React Blog UI.
- `week-2/` — React practice plus Express/MongoDB APIs for To-Do, authentication, and JWT-secured Notes.
- `week-3/` — Full-stack To-Do, Multer image upload, and Task Manager with filtering.
- `week-4/` — Capstone E-Commerce MERN application, deployment configuration, testing/debugging notes.

## Run
Each React client has its own `package.json`; each Express server does too. Copy `.env.example` to `.env` and provide MongoDB/JWT values where required.

> Dependencies are intentionally not committed. Run `npm install` in each application directory.
