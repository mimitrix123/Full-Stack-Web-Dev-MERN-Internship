# Assignment Solution Map

## Week 1
- Practice 1: `week-1/portfolio` personal portfolio.
- Practice 2: responsive nav in `portfolio/index.html` + CSS/JS mobile toggle.
- Practice 3: `portfolio/script.js` form validation.
- Practice 4: `week-4/ecommerce` contains the complete e-commerce landing/app implementation.
- Practice 5: Grid/Flexbox used throughout portfolio and React UIs.
- Assignment 1: responsive portfolio with About, Education, Projects, Contact.
- Assignment 2: five reusable React components in `react-components`.
- Mini project: searchable/filterable JSON-backed React Blog UI.

## Week 2
- React practice: `week-2/react-practice` covers product props, state, add/delete To-Do, React Router and CSS.
- Assignment 1: `week-2/todo-api` with POST/GET/PUT/DELETE and MongoDB.
- Assignment 2: `week-2/auth-api` with bcrypt password hashing and JWT.
- Mini project: `week-2/notes-api`, JWT-secured CRUD Notes API.

## Week 3
- Practice: `week-3/task-manager/server` provides user auth, MongoDB/Mongoose, CRUD, JWT; routes are Postman-ready.
- Assignment 1: `week-3/task-manager` full-stack React + Express + MongoDB Task Manager with auth, CRUD and filtering.
- Assignment 2: `week-3/image-upload` Multer upload endpoint plus React preview/display.
- Mini project: Task Manager with login and filtering.

## Week 4
- Practice 1–2: `week-4/ecommerce` connects React to Node API and implements login.
- Practice 3: deployment instructions in `week-4/ecommerce/README.md`.
- Practice 4: products + cart + checkout flow.
- Practice 5: repository contains all four weeks and this solution map.
- Capstone: E-Commerce option implemented with products, auth, cart, orders, and admin product controls.
